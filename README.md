# My First React App (Vite) 🚀

This is my very first React project built using **Vite**. It features a simple Welcome Application that interacts with user input and manages state efficiently.

## 🌟 Key Features
- **Fast Development**: Powered by Vite for lightning-fast Hot Module Replacement (HMR).
- **Interactive UI**: Users can enter their names and see a personalized greeting.
- **State Management**: Uses React `useState` hook to handle user data.
- **Conditional Rendering**: Shows specific messages based on user interaction.

## 🛠️ Tech Stack
- **React**: Library for building user interfaces.
- **Vite**: Modern frontend build tool.
- **JavaScript (ES6+)**: Programming language used.
- **CSS3**: For basic styling and layout.
